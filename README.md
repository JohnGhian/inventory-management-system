# Inventory Management System

This is a simple inventory management system I built using Python.

I created this project to practice building a program that can be useful for a small store or business. It allows the user to manage products, check stock, and save inventory records in a CSV file.

## What It Can Do

- Add new products
- View all products
- Search for a product
- Update product stock
- Delete products
- Calculate the total inventory value
- Save inventory records to a CSV file
- Handle invalid price and quantity inputs

## How It Works

When the program starts, it shows a menu where the user can choose what they want to do.

For example, a user can add a product by entering its name, price, and quantity.
